词库表关系

三层结构：统一主词典 + 多本词书关系 + 专业领域释义。
物理库文件：data/lexicon/zhimi-lexicon.sqlite

主表在哪里？ 主表是 words，存放在 /home/giga/englishProject/data/lexicon/zhimi-lexicon.sqlite 里。一词一行，负责搜索、音标和跨词书常用义； 四级 / 六级 / 考研等书内释义不在主表，而在 word_book_entries。

Layer 1 · 主词典

words — 统一词条，可全局搜索

Layer 2 · 词书关系

books + word_book_entries — 按词书取释义

Layer 3 · 专业领域

domains + word_domain_meanings — 计金生医等

关系总览

主词典 词书关系 专业领域 构建元信息 箭头：外键方向（N → 1 指向被引用主键）

各表字段

words

主表 · Layer 1

统一主词典：一词一行。搜索、默认释义、音标都从这里取。

PK id规范词条 ID，通常与 word 相同
word展示用原文
word_norm小写规范化，用于搜索 / 去重
usphone / ukphone / phone美音、英音、通用音标
phonetics_json音标变体集合
pronunciation_refs_json原仓库发音引用标识
meanings_json跨词书常用义（主表只存这个，不存各书释义）
translations_json 等词性结构、短语、例句、真题句、同反义、记忆法、考题
review_required缺音标等需复核标记
book_count出现在几本词书中

books

词书 · Layer 2

23 本逻辑词书元数据（四级、六级、考研、雅思…）。

PK id如 cet4 / postgraduate / ielts
name / short_name全称与短名
category / levelexam / school / business 与级别文案
unique_words该书唯一词数

word_book_entries

关系 · Layer 2

词 ↔ 词书多对多。按词书学习时优先读这里的释义。

PK (word_id, book_id)联合主键
FK word_id→ words.id
FK book_id→ books.id
meanings_json该词书侧重点释义
word_rank书内排序
source_*_json原始册次与来源追溯

domains

领域 · Layer 3

专业领域字典：计算机、金融、生物、医学（可继续扩展）。

PK idcs / finance / biology / medicine
name / name_zh英文名与中文名
description领域说明

word_domain_meanings

关系 · Layer 3

词的专业释义层。不污染考试词书释义；目前表结构已就绪，数据待补。

PK (word_id, domain_id)联合主键
FK word_id→ words.id
FK domain_id→ domains.id
meanings_json该领域释义列表
notes / source备注与来源

meta

构建信息

导入校验用键值，如 source_sha256、word_count。

PK key元数据键
value元数据值
